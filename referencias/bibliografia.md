# Bibliografía y referencias

Recursos para profundizar, organizados por tipo. Todos son de acceso libre salvo donde se indique.

## Documentación oficial (la fuente más confiable)

- **NumPy** — https://numpy.org/doc/stable/
  - Guía para principiantes: https://numpy.org/doc/stable/user/absolute_beginners.html
- **Pandas** — https://pandas.pydata.org/docs/
  - "10 minutes to pandas": https://pandas.pydata.org/docs/user_guide/10min.html
  - Guía de usuario: https://pandas.pydata.org/docs/user_guide/index.html
- **Matplotlib** — https://matplotlib.org/stable/index.html
  - Tutorial de introducción: https://matplotlib.org/stable/tutorials/pyplot.html
  - Galería de ejemplos: https://matplotlib.org/stable/gallery/index.html
- **Seaborn** — https://seaborn.pydata.org/
  - Tutorial oficial: https://seaborn.pydata.org/tutorial.html
  - Galería de ejemplos: https://seaborn.pydata.org/examples/index.html

## Libros

- **Géron, A. (2019).** *Hands-On Machine Learning with Scikit-Learn, Keras & TensorFlow* (2.ª ed.).
  O'Reilly. — De aquí proviene el dataset del taller; su capítulo 2 es un recorrido completo de
  análisis de datos con este mismo conjunto.
  Repositorio con notebooks: https://github.com/ageron/handson-ml2

- **McKinney, W. (2022).** *Python for Data Analysis* (3.ª ed.). O'Reilly. — Escrito por el creador
  de Pandas. Disponible **gratis** en línea: https://wesmckinney.com/book/

- **VanderPlas, J. (2016).** *Python Data Science Handbook*. O'Reilly. — Excelente para NumPy, Pandas
  y visualización. Disponible **gratis** en línea:
  https://jakevdp.github.io/PythonDataScienceHandbook/
